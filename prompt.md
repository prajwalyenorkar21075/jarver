Work on this JARVIS project carefully.

Before changing anything:
1. Inspect the existing project structure.
2. Understand the current frontend and backend.
3. Do not delete or break existing functionality.
4. Make only the changes required by the task.
5. Run appropriate tests/build/lint checks after changes.
6. Fix errors you introduce.
7. Keep changes small and reviewable.
8. Never expose or commit API keys, passwords, or secrets.
9. Summarize what you changed and any remaining issues.

For this iteration, inspect the project and identify the most useful next improvement.
Do not make large architectural changes without a clear reason.
